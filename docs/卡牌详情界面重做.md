# 卡牌详情界面（全屏 + 三页签 + 实际战场微演示）

## 结构
- 全屏详情，背景按卡牌稀有度生成渐变氛围。
- 顶部：关闭、卡名、稀有度/类型、等级。
- 中央卡牌舞台：3D 模型/法术投射物 + 稀有度光晕，支持拖动旋转。
- 舞台右侧：圣水、等级、稀有度、核心属性、定位标签。
- 三页签：动画 / 属性 / 简介（原升级页已删除）。
- 本次整体放大字号：卡名 34、页签 21、区块标题 22、属性值 27、说明 16-18；所有动态内容面板改为 PanelContainer，避免零高度导致文字重叠。

### 动画（第一栏）
- 实际战场微演示、定位、使用提示、优势/劣势、搭配建议。

### 属性（第二栏）
- 两列属性卡片，生命/伤害/DPS 显示当前等级 → 下一等级。
- 法术隐藏生命，零值属性隐藏；下方展示召唤/多目标/多段机制。

### 简介（第三栏）
- 显示官方风格短描述、类型/稀有度/圣水与定位标签。
- 常用卡人工整理，其余卡按卡牌定位生成短描述。

### 实际动画（第一栏）
- 播放器直接使用实际 battlefield：
  - 真实战场地面、河流、桥与装饰；
  - 真实 `Unit` 模型、真实单位血条；
  - 真实 `Bullet`/`Spell` 子弹与法术特效；
  - 真实 `Camera3D`，全局展示双方战场。
- `BattleManager` 新增 `showcase` 模式：加载真实 `battle.tscn`，跳过 AI/网络/回放/开场/战斗计时，保留真实战场与单位结算，隐藏 HUD 其它部分只留血条。
- 每张卡两段：优势 · 克制 / 劣势 · 被克制；可切换、循环播放。
- 录制动画优先，未录制时使用专属/标签模板。

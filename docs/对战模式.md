# 对战模式接入（P0 已完成，P1/P2 进行中）

## 官方模式体系（参考）
1. 天梯/排位：Trophy Road 1v1、Path of Legends 排位（卡等归一、赛季段位）。
2. 挑战/锦标赛：经典挑战、大挑战、主题活动、全球锦标赛（15 胜制）、私人锦标赛、友谊战自定义。
3. 派对模式（轮换）：2v2、2v2 冲线 Touchdown、双倍/三倍/七倍圣水、突然死亡、选卡 Draft/Triple Draft、经典卡组、超级卡组 Mega Deck。
4. 部落战 2（River Race）：1v1、决斗 Duel（多套卡组 Bo3）、船战 Boat Battle、部落战联赛/斗兽场。
5. 训练营/练习。

## 本项目实现状态

### P0 已完成（2026-11-19）
核心文件：
- `scripts/core/BattleModes.gd`：模式表 + 当前选择 + 经典卡组池（8 套），提供 `mode_label()` 规则摘要。
- `scenes/mode_select.tscn` + `assets/ui/ModeSelect.gd`：模式选择页（7 个模式、选中高亮、规则徽标、底部开始按钮）。
- `BattleManager`：读取模式并应用——`elixir` 倍率（固定不随回合加速）、`sudden_death`（推塔即胜/到时比塔血）、`deck=classic`（双方随机经典卡组）、`level=fixed`（固定 11 级）。
- `AISystem`：经典卡组模式使用同一模式卡组；法术伤害等级走 `mode_level()`。
- `Unit`：初始化与死亡法术的等级统一按模式卡等结算。
- `HUD`：计时药丸下方显示模式徽标；圣水徽标按倍率显示「双倍/三倍/七倍圣水」。
- `MainMenu`：开始对战 → 模式选择页。
- `ReplayRecorder/ReplayUI`：录像 meta 写入 `mode`（规则快照）；旧录像无 mode 时按标准规则重演。

开发/自动化开关：
- `CR_MODE_ID=double_elixir|triple_elixir|seven_elixir|sudden_death|classic_deck|custom` 直接以该模式进入战斗。
- `CR_MODE_ELIXIR=7` 配合 `CR_MODE_ID=custom` 测试自定义倍率。
- 联机对战（LAN）暂时强制标准规则，P1 再同步房间规则。

验证截图：`tools/mode_select_a.png`、`tools/battle_mode_a.png`（双倍圣水）、`tools/battle_classic_a.png`（经典卡组）。

### P2 进行中（2026-11-19）

# 新竞技场入场动画 / 奖杯保护

## 奖杯不为负
- `PlayerData.add_trophies()` 对负数扣杯增加保护：
  - 最低不低于 `0`；
  - 保留历史最高竞技场奖杯门保护（不跌破当前最高竞技场门槛）；
- `remove_trophies()` 同样夹到 `0`；
- 读取旧存档时把负数奖杯修正为 `0`，避免历史坏档继续显示负数；
- 战斗结算继续使用 `add_trophies()`，所以正常胜负/掉杯都会经过保护。

## 入场动画设计方案：「王冠破晓 · 新竞技场」
- 触发：主菜单加载时比较当前竞技场与 `arena_seen`；只有**第一次进入更高竞技场**才播放。首次加载只记录，不打扰。
- 时间线（约 3.5 秒，可点击跳过）：
  1. **暗场降临**：全屏深蓝黑幕 0.35s 淡入，背景保留微弱金色星尘。
  2. **辉光觉醒**：中央 28 道金色旋转光束 + 三层扩散圆环，星尘粒子缓慢漂浮。
  3. **竞技场徽章**：金色双环徽章从 0.15 倍弹入，内含皇冠图标与竞技场序号，带金色外发光。
  4. **名称揭晓**：`NEW ARENA` 眉标、竞技场名称、`竞技场 N`、新解锁卡牌数量依次上浮淡入；
     下方展示本竞技场新解锁卡牌的**官方卡图**（最多 4 张，带卡名，超出显示 +N）。
  5. **停留/收束**：约 3.15s 后整体淡出，标记已看过。
- 视觉语言：深蓝黑底 + 皇室金 + 星尘青白，延续主菜单的玩具沙盘/皇室金蓝体系，不依赖外部动画资源。
- 代码：`assets/ui/ArenaIntro.gd`，主菜单 `_maybe_play_arena_intro()` 触发；状态存 `PlayerData.arena_seen`。

# 账号与云存档系统

## 目标
- 必须登录账号后进入游戏（可用本机账号离线进入）。
- 所有玩家进度按账号分目录存储，并在联网时上传 LootLocker 云端。
- 同一设备同一账号登录后 **30 天免登录**。
- 设置界面提供「切换账号 / 退出登录」。

## 登录方式
- 邮箱 + 密码，密码至少 6 位。
- 在线：LootLocker White Label 账号（`LL_WhiteLabel.SignUp` / `LoginAndStartSession` / `StartSession`）。
  - 注册后通常需要完成邮箱验证才能建立云端会话；在此之前可先用本机账号进入。
- 离线兜底：本机账号索引 `user://accounts_index.cfg`，只保存邮箱、账号 id 和密码哈希，不保存明文密码。
- 登录入口：`scenes/account_login.tscn`；主菜单未登录会跳转到此页。

## 本地存档隔离
- 默认旧存档：`user://player_data.cfg`（仅未登录/开发模式）。
- 账号存档：`user://accounts/<email_sha256前24位>/player_data.cfg`。
- 首次登录账号时，如果账号目录不存在且旧存档存在，会把旧存档迁移到该账号。
- `PlayerData.use_account(id)` 切换账号并加载对应存档；每次保存写 `meta.saved_at` 时间戳。
- 头像/音量等设备设置仍为设备级；玩家进度（金币/宝石/卡牌/卡组/奖杯/宝箱/挑战等）按账号隔离。

## 30 天免登录
- 登录成功后写 `user://account_session.cfg`：email、account_id、expires（当前时间 + 30 天）、online。
- 启动时 `AccountManager._boot()` 校验有效期；有效则恢复账号并自动加载存档，登录页显示自动登录后直接进入主菜单。
- 过期/退出登录后清除 session，需要重新输入密码。
- 在线会话使用 LootLocker 缓存的 white-label token 调用 `StartSession` 刷新；token 失效时降级为本地存档，不阻塞进入游戏。

## 云端同步
- 服务：LootLocker Player Files。
  - 上传：`POST {settings.url}/game/player/files`，multipart 字段 `key=cr_player_data`、`file=player_data.json`，Header `x-session-token` + `LL-Version: 2021-03-01`。
  - 下载：`GET /game/player/files/key/cr_player_data`；如返回 `requires_download_link`，再调用 `POST /game/player/files/{id}/download-link/v1` 取临时 URL。
  - 文件内容：`{version, account, saved_at, data(base64 cfg)}`。
- 登录/自动登录时先比较云端与本地 `saved_at`：
  - 云更新或首次在新设备登录 → 下载并覆盖本地，再加载；
  - 本地更新 → 上传本地；
  - 云端 404 → 上传本地。
- 游戏内每次 `PlayerData.save_data()` 会通知 AccountManager，防抖 2 秒后上传；失败保留 dirty 并 30 秒后重试。
- 退出登录前会尝试上传一次。

## 测试工具 / 环境变量
- `CR_SKIP_ACCOUNT=1`：跳过登录门禁（开发/截图/旧测试用）。
- `CR_ACCOUNT_OFFLINE=1`：强制离线登录流程，不请求 LootLocker。
- `CR_ACCOUNT_DATA_DIR=<绝对路径>`：把账号 session/index/存档根目录改到指定目录（测试用；默认 `user://`）。
- `tools/account_system_test.tscn`：本机注册 A/B、账号隔离、30 天会话、自动登录恢复；`[Account] PASS=true`。
- `tools/cloud_save_test.tscn`：用 LootLocker 游客会话临时上传/下载/删除 `cr_player_data`，验证云链路（不涉及真实账号）；`[CloudTest] PASS=true`。
- 菜单门禁测试：未登录启动菜单会跳转 `AccountLoginUI`。

## 注意
- 云端账号依赖 LootLocker 项目的 White Label 登录配置；正式包请使用生产 API key/域名，并完成邮箱验证流程配置。
- 本机离线账号哈希仅作为离线兜底，不应作为正式跨设备安全方案；正式账号安全由 LootLocker 服务端负责。

# 新账号头像 / 教程后对话引导

## 新账号头像
- 取名弹窗确认后，如果是新账号（`name_chosen` 原本为 false），自动弹出 `AvatarSetupDialog`。
- 头像弹窗提供：
  - 上传图片（Android 原生文件选择 / Web 文件输入）
  - 随机皇家头像
  - 使用当前头像 / 稍后再说
- 上传图片自动**居中裁剪最大正方形**再缩放到 128×128，避免非正方形图片被拉伸变形。
- 头像按账号保存到该账号存档目录的 `avatar_custom.png`，不会串号。

## 教程完成后的对话引导
- `PlayerData.tutorial_guide_seen` 控制只引导一次。
- 完成新手教程回到主菜单后，皇家顾问以对话气泡 + 打字机方式介绍：
  1. 训练结束
  2. 开始对战 / 派对
  3. 卡组配置
  4. 宝箱与商店
  5. 联机与好友
  6. 部落
  7. 收藏与排行
  8. 出发吧
- 底部显示步骤圆点、进度和「继续 / 开始探索」；右上角可跳过。
- 若同时进入新竞技场，优先播放竞技场动画，对话引导留到下一次回主菜单。

## 验证
- `tools/avatar_tutorial_test.tscn`：非正方形裁剪、新账号头像提醒、教程后对话引导均通过，`PASS=true`。

## 互动巡览（2026-11-21 增强）
- 新增 `TutorialTour` autoload 记录当前巡览站点。
- 对话引导中的模块步骤提供「带我去看看」：
  - 卡组配置 → 宝箱 → 联机 → 部落 → 收藏；
  - 经 LoadingScreen 进入对应场景；
  - 场景内由 `TourTip` 展示该模块的细节说明（点哪里、注意什么）；
  - 点「我明白了，返回主菜单」回到菜单继续下一站，也可随时结束引导。
- 巡览期间主菜单跳过开场动画，避免每进一个模块都等一次开场；新竞技场动画优先。
- 验证：`tools/tour_flow_test.tscn` → `[TourFlow] step=true go=true tip=true`，`PASS=true`。

# 视觉改造记录（详细参数，供查阅；不必每次加载）

## 渲染
- `assets/shaders/toon_unit.gdshader`：伪太阳光 unshaded + 边缘光 + 描边；`u_flash/u_freeze/u_poison/u_dark` instance uniform 管状态；`vertex_srgb`、`emissive_boost` 两个 uniform。
- 渲染器差异：`gl_compatibility` 自动把顶点色转线性 → `UnitModelKit` 里检测渲染器设 `vertex_srgb=0`。
- `Battlefield._setup_lighting()`：Compatibility 用 曝光0.90/环境光0.48/阳光1.15，mobile/vulkan 用 1.0/0.55/1.35；环境 contrast 1.06、saturation 1.05。
- 太阳 `SUN_DIR=(0.42,0.72,-0.42)`（影子落左下）；`shadow_blur=1.6`；贴地投影椭圆、alpha 0.60、偏移(-0.30,+0.36)。

## 单位
- `UnitModelKit.VISUAL_SCALE = 1.5`；Q 版比例：头 0.145（约身高1/4）、大眼+高光+腮红、短腿大靴。
- 结构：`root(Body)`，Body 下挂 `Weapon`、`LegL`、`LegR`（武器/腿独立节点供动画）。
- `CardVisualCatalog.spec_for(card_name, team)` 117+ 卡映射。
- `UnitVisualAnim`：idle/walk/attack/hit/die；`w = t * 5.5 * speed`，speed 传真实移动速度 `config.move_speed*0.05`；建筑只做轻微后坐。

## 子弹（`ProjectileKit`，16 种）
arrow / musket / fireball / energy / plasma / lightning / cannonball / bomb / snowball / ice / spear / log / rocket / firework / axe / potion
- 材质 `light_material()`：emissive_boost 1.45、细描边；axe/plasma 飞行自旋。
- 类型判定 `Bullet._get_bullet_type()`：ID 特判(96 axe,28 plasma,43 firework,91 log,1 arrow,2 cannonball,3 energy) → attack_type(2 lightning/4 fireball/5 plasma) → 卡名语义 → 射程≥2m 兜底 energy → 近战 normal。
- 出膛高度：建筑 +2.0m，地面 +0.75m；视觉缩放 `clampf(size*2.2, 0.75, 1.7) * 1.5`。

## 战场（`scenes/Battlefield.gd`）
草地棋盘+格线 shader(`ground.gdshader`)、河水 shader(`water.gdshader`)、木板桥(支撑桩/侧梁/球头栏杆/桥头灯)、石边界、沙岸/芦苇/荷叶、场内外树石花丛栅栏、四角队旗。
- 相机 `battle.tscn` Camera3D `size=36.5`；血条高度 ×1.5。

  - `extra_spell` 附加法术数组 `[伤害, 半径, 攻击类型, 目标类型, 触发时机]`；`spawn_unit` 召唤数组 `[卡ID, 数量, 冷却毫秒/-1一次性]`；`multiple_targets` 多目标 `[数量, 连击类型]`；`multiple_process` 特殊子弹 `[角度, 数量, 速度, 距离, 模式]`
  - 空数组一律写 `[]`；数组内数字用英文逗号分隔，如 `[118, 2, -1]`。

## 回放子弹流畅度
- 原因：回放子弹/单位来自快照，旧快照 0.1s 采样 + 线性插值；高速子弹每帧位移大，看起来不像对战的逐帧飞行。
- 修复：快照采样间隔从 0.1s 提升到 0.033s（目标 30Hz），MAX_SNAPSHOTS 提升到 6000；新录像的子弹位置/旋转插值更密，飞行更自然。
- 旧 v3 录像仍是旧采样率，需要重新录制才是新流畅度；实际帧率低时仍按实际帧采样。

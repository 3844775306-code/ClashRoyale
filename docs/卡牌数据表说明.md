# 卡牌数据表说明

## 谁是权威数据
- 战斗与卡组/升级/详情界面统一通过 `BattleManager.load_card_configs()` 读取 `data/units_level11_utf8.csv` 或 `data/units_level11.csv`。
- 两文件现在都按 UTF-8 保存；加载时按**修改时间最新**选一张，避免“改了旧表不生效”。
- 只有 CSV 无法解析时才回退到 `_make_card` 硬编码，正常游戏不会使用硬编码数值。

## 卡组界面同步
- 打开卡组配置/卡牌详情/升级界面时都会重新读取 CSV，不使用旧缓存。
- 卡组配置窗口重新获得焦点时会检查 CSV 修改时间，变化则自动重载场景。
- 卡牌详情里显示：生命、伤害、攻击间隔、DPS、攻击距离、溅射半径、视野、目标类型、碰撞半径等，均来自 CSV。
- 卡牌列表卡片只显示费用/等级等摘要；细项要打开详情。

## 不来自 CSV
- 稀有度、解锁竞技场、卡牌拥有数量/等级、升级消耗来自 PlayerData/CardRarity。
- `.xlsx` 不会被运行时读取。

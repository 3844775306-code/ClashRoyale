# 宝箱视觉 / 派对卡组入口 / 互动教程巡览

## 宝箱
- 宝箱界面队列中的宝箱图标改为 3D `Chest3DPreview`，与当前宝箱同款模型和稀有度配色。
- 领取奖励动画 `ClaimAnimation` 中的宝箱也使用 3D 预览。
- 新增 `ClaimAnimation.play_many()`：
  - 一键领取多个奖励时按网格显示多个奖励图标（最多 9 个），并显示「共 N 项奖励」；
  - 收藏等级、主题赛季、卡牌大师的一键领取均已改为多奖励动画。

## 派对卡组入口
- `PlayerData.has_party_deck()` 判断是否已配置 8 张派对卡组。
- 进入 `PartySelect` / `NetworkLobby` 时若未配置：
  - 弹出「派对卡组未配置」提醒，说明全卡/固定 11 级/与标准卡组分离；
  - 「去配置」通过 LoadingScreen 缓冲后进入 `party_deck.tscn`；
  - 可稍后再说。
- 派对界面「配置派对卡组」按钮和配置完成返回也统一走 LoadingScreen。

## 教程后互动巡览
- `TutorialTour` autoload 记录当前巡览站点。
- 菜单对话新增「带我去看看」：
  - 卡组配置 → 宝箱 → 联机 → 部落 → 收藏；
  - 通过 LoadingScreen 进入对应场景；
  - 进入后由 `TourTip` 显示该模块的细节说明；
  - 「我明白了，返回主菜单」后回到菜单，继续下一站；也可随时结束引导。
- 巡览期间主菜单跳过开场动画；若同时有新竞技场动画，竞技场优先。
- 巡览期间不会弹派对卡组提醒。

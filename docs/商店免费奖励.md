# 商店免费奖励

- 每天只有一件免费卡牌。
- 周日固定为 **5 张史诗卡，种类按日期随机**。
- `PlayerData.shop_free_claimed_day` 记录当天是否已领取。
- 领取后 `ShopUI` 会标记免费 offer 为 sold 并写入领取日期。
- `ensure_daily_shop_offers()` 对已领取当天直接返回，不会补出第二件免费；旧存档的 sold 免费 offer 也会自动识别为已领取。
- 周日免费卡数量固定为 5 张，不再是旧版的 25 张。
- 验证：`shop_free13` → 周日免费 1 件、qty=5、领取后再次 ensure 免费数 0，`PASS=true`。

# 卡牌动画录制工作台

## 入口
- 卡组配置界面 →「🎬 配置动画」按钮
- 进入真实 `battle.tscn` 的 showcase 模式：无 AI、无开场、无战斗计时、无其它 HUD，只保留真实战场和血条。
- 相机使用全局战场视角（完整看到双方场地），录制/回放统一使用该视角。

## 等级 / 暂停 / 清空

- 录制与回放时，所有卡牌、法术和皇家塔固定 11 级。
- 「暂停」使用整棵战斗场景暂停：单位、子弹、法术全部冻结；暂停时可继续放卡。
- 「清空战场」会清掉所有单位/子弹/法术并重新生成 6 座 11 级皇家塔，塔恢复满血。

## 操作
- 进入后默认暂停；点击顶部「继续/暂停」按钮切换战斗运行状态。
- 暂停时可点击战场放置卡牌：
  - 底部：我方卡牌桌（全部卡牌，可左右滑动 + 搜索）
  - 顶部：敌方卡牌桌（同样可滑动 + 搜索）
  - 放置不消耗圣水
- 顶部下拉：
  - 录制目标卡牌
  - 优势 / 劣势
- 录制按钮：
  - 开始录制 / 结束录制 / 重新录制
  - 上传录制：保存到账号目录 `card_animations.json`
- 「清空战场」只清演示单位和法术，不删除初始塔。

## 回放
- 卡牌详情「玩法」页优先读取该卡 + 优势/劣势的录制：
  - 按录制事件的时间、阵营、卡牌、坐标依次放置；
  - 使用真实战场、真实单位、真实子弹、真实血条；
  - 没有录制时回退到原来的三张专属/标签模板演示。
- 录制数据格式：
  ```json
  {"time":0.5,"team":0,"card_id":7,"x":-6.5,"y":0,"z":0.5,"spell":false}
  ```

## 验证
- `studio_test12`：录制 2 条指令 → 上传 → 详情实际战场回放，`PASS=true`。
- `studio_level13`：塔/卡 11 级、清空后 6 座塔满血。
- 卡牌详情实际战场测试 `PASS=true`。


## 已录制提示 / 动画相机
- 选择录制目标时，下拉列表中已录制的卡牌会显示 `✓` 前缀（按优势/劣势分别判断）。
- 动画播放一开始就切到目标区域的近景，不会先停留在全局俯视；
  - 相机从第一条录制指令开始跟随目标录制单位；
  - 目标未出场或已死亡时，改为跟随最早出现的非皇家塔存活单位；
  - 舞台左上角显示当前跟随单位名称；
  - 录制时间结束后恢复全局相机。
- 动画战场侧翼皇家塔默认统一为公主塔，避免厨师塔/飞刀塔/王子塔影响示范画面。


## 云端动画
- 本地录制保存到账号目录 `card_animations.json`。
- 打开动画详情或动画工作台时会自动：
  1. 拉取该账号的云端录制；
  2. 将本地已有录制按更新时间合并上传到 `cardanim:<player_id>`；
  3. 播放时优先使用云端录制，云端没有时才用本地；
  4. 云端和本地都没有才回退默认模板。
- 工作台「上传录制」会同时写本地与云端；云端失败会提示仅保存本地。
- 动画演示使用全账号共享的云端动画库 `cardanim:library`。
- 账号登录后自动把当前设备已有录制上传云端，并兼容迁移旧版 `user://card_animations.json` 与旧版按账号保存的 `cardanim:<player_id>`。
- 云端请求节点在暂停状态下继续工作，避免录制工作台暂停时上传卡住。
- 云端读取失败时不会覆盖云端，并会在下次播放时重试。
- 首次进入动画时先用本地/默认演示填充战场，云端同步完成后自动切到云端录制，不再出现空白等待。

# 新手教程模块

- 奖杯为 0 且未完成教程的玩家，进入主菜单后自动跳转到 `scenes/tutorial.tscn`。
- 其他玩家可从主菜单底部「新手教程」手动进入。
- 教程共 6 步：欢迎、六张起始卡、圣水、部署、公主塔/国王塔、完成。
- 起始卡：弓箭手、万箭齐发、骑士、亡灵、巨人、火球；默认出战卡组即为这六张。
- 完成或跳过会写入 `player/tutorial_done`，之后不会自动跳转。
- 最后一步「开始第一场」会进入**实战训练**：真实战场、关闭敌方 AI。 
- 实战训练先提示部署第一张卡，成功后提示圣水恢复与费用节奏，最后返回主菜单。
- 也可直接返回主菜单。

Web 端 emoji 兼容：`WebTextCompat` 自动把 UI 文本中的 emoji 替换为中文词，避免无系统 emoji 字体导致方框/乱码。

- 完成实战训练奖励 1 个宝箱（跳过训练不发放）。

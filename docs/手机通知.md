# 手机通知

## 已接入
- Android 本地通知插件 `NotificationPlugin`
- Android 13+ 动态请求 `POST_NOTIFICATIONS` 权限
- 通知渠道：游戏消息
- 触发事件：
  - 好友新消息
  - 好友申请
  - 邮箱/官方公告等 `PlayerData.add_mail`
  - 部落未读消息
- 点击通知回到游戏

## 构建
- Android 导出已启用 Gradle 自定义构建
- 插件源码：`android/build/src/main/java/com/godot/game/NotificationPlugin.java`
- 权限与插件注册：`android/build/src/main/AndroidManifest.xml`

## 限制
- 这是本地通知，不是 FCM 服务器推送。
- 应用进程完全被杀掉后，Godot 收不到新消息，因此不会产生通知；要做到关掉游戏仍收到，需要服务器 + FCM 推送。

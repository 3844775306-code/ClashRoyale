# 社交系统（名字 / 个人主页 / 好友 / 邀请）

## 实际名字
- 部落：`ClanManager.get_player_name()` 优先返回 `PlayerData.player_name`，不再使用 LootLocker 游客缓存名。
- 排行榜：提交元数据包含 `player_name / avatar_seed / avatar_index / account`；自己的条目显示 `PlayerData.player_name`，并在改名后立即重新提交。
- 部落成员/聊天：自己的名字显示本地实际名字；新建/加入部落、聊天、改名同步都使用实际名字。
- 账号登录后，如果尚未取名，会用邮箱前缀作为初始玩家名（之后仍会弹出取名确认）。
- 改名时 `NameDialog` 会同步调用 `LeaderboardAPI.submit_trophies` 与 `ClanManager.sync_my_profile()`。
- 排行榜兼容旧条目：若元数据没有名字，则显示“玩家 #短ID”，不会再显示裸 member id。

## 个人主页
- `scripts/ui/PlayerProfileDialog.gd`：头像、名字、奖杯、排名、部落/职位、这是你提示。
- 入口：排行榜头像、部落成员头像、部落聊天头像。
- 页面内提供“添加好友”和“邀请入房（同局域网）”。

## 搜索添加好友 / 主菜单好友模块
- 主菜单左上角「好友」模块重新设计为皇室风格卡片：金边深色底、奖章图标、在线绿点与红色请求角标；显示好友数/同局域网在线数与待处理请求数，点击打开好友中心；收到请求会弹窗同意/拒绝。
- 好友中心（`assets/ui/FriendCenter.gd`）重新设计：
  - 金边皇室弹窗、统一字号/间距/分区标题；内容区整体可滚动，修复之前内容显示不全；
  - 搜索卡片有明确最小高度，修复 VBox 高度为 0 导致的 UI 重叠和输入框点不到的问题；
  - 搜索框实测尺寸 `512×48`，可正常点击输入；
  - 搜索卡片固定在顶部，下方依次为「搜索结果 / 好友请求 / 我的好友」，底部状态与关闭按钮始终可见；
  - 好友/请求行使用深色圆角卡片 + 头像 + 在线/请求状态；
  - 输入玩家 ID 或名字搜索；搜索来源包括排行榜、部落成员、本机好友、同局域网在线玩家；
  - 搜索结果按状态显示「发送请求 / 等待同意 / 同意 / 已是好友」；
  - 搜索结果点「添加」即加入好友；
  - 好友列表显示绿点在线状态，可「邀请入房」。
- 同局域网在线状态：`FriendManager` 每 2.5 秒广播 presence 心跳，收到好友心跳后 8 秒内显示在线。
- 联机房间好友列表增加「搜索添加好友」入口。

## 好友（请求制）
- `FriendManager`（autoload）：好友列表/请求按账号保存在 `friends.cfg`（位于当前账号存档目录）。
- 加好友改为**请求-同意**流程：
  - 搜索/个人主页点“发送好友请求”后，只记录为“等待对方同意”；
  - 对方在主菜单弹窗、好友中心「好友请求」里点“同意”后才互相加入好友；
  - 拒绝会清除请求；请求会定期重发（同局域网），同意通知会重发并等待对方 ack。
- 清理已结束请求：同意/拒绝后从待处理列表移除；主菜单好友模块显示待处理请求数。
- 联机房间新增“好友”和“邀请好友”：
  - “好友”打开好友列表，逐人邀请；
  - “邀请好友”向同局域网广播当前房间码和房主 IP；
  - 好友端在联机房间或主菜单收到邀请弹窗，确认后进入联机房间并自动尝试占座。
- 邀请使用 UDP 24511 端口广播；需要同一局域网，Android 已开启 `change_wifi_multicast_state` 权限。
- 好友列表目前为本地/账号数据（不进入云存档）。

## 限制
- 好友请求/同意/在线状态/房间邀请通过同局域网 UDP 广播传输；跨互联网添加好友需要额外后端中继。

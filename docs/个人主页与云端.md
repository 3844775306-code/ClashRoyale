# 个人主页与云端资料

## 云端公开字段
`ProfileAPI.public_payload()` / Presence heartbeat / 本地个人主页统一包含：

- 身份：player_id、name、avatar_seed、avatar_index
- 部落：clan、role
- 奖杯：trophies、highest_trophies、arena
- 战绩：battle_wins/losses/draws、three_crowns、current_streak、best_streak、season_crowns
- 收藏：collection_level、current_deck（id + level）、top_cards（使用频率前 3）、recent_battles
- 徽章：trophy_badges、mastery_badges、season_badges
- 简介：bio
- 部落捐赠：donations
- 自定义头像由 CloudAvatar 独立上传

## 个人主页卡组页
- 等级标签和卡名同排显示，等级标签固定宽度不换行。
- 新增「最常使用」前 3 张卡（按历史使用次数），并上传云端 `top_cards`。

## 卡牌大师数量
- 不再使用 `card_mastery.size()`（会为全部 126 张卡创建空记录）。
- 现在统计真正有使用记录（uses > 0）的卡牌数量。
- 排行榜/个人主页下一次提交或登录后刷新。

## 排行榜
- 上传：最高奖杯、当前奖杯、周净增、周胜场、周三冠、收藏等级、卡牌大师数、场次、头像、部落。
- 提交前调用 `ensure_week()`，避免本周字段为空导致周榜为空。
- 每周榜按当前 `week_key` 过滤。

## 快捷登录
- 优先复用本机 session 的 access token；失效后依次尝试 session refresh、账号索引 refresh，避免刷新令牌轮换导致快捷登录误报会话过期。

## AI 个人主页
- AI 对手的场次、胜率、奖杯、竞技场、最高奖杯、连胜、收藏等级、卡组、近期战绩、捐赠和简介按同一套数据生成，保证互相合理。
- AI 卡组固定 8 张；AI 主页不显示添加好友/邀请入房。
- 验证：`profile_test22` → 云端字段与 AI 主页自洽，`PASS=true`。
